# Code with Rakib — Portfolio starter

## Run
Open `index.html` in a browser, or serve this folder with a local development server.

## Customize before publishing
1. Replace `hello@example.com` with your real email address.
2. Update GitHub and LinkedIn links in the sidebar.
3. Replace project concepts with real project descriptions, screenshots and repository/live URLs.
4. Update the skills and experience details to match your actual background.
5. Replace `assets/rakib-cv.pdf` with your own CV PDF. The download buttons already point to that filename.
6. The hero illustration is `assets/rakib-coding-illustration.webp`.

This is a responsive front-end starter. To make it a Laravel application, move the page into a Blade view (for example `resources/views/portfolio.blade.php`) and move the assets into `public/assets`; then update the asset references to Laravel's `asset()` helper. The contact CTA currently opens the visitor's email app; connect it to a Laravel form/controller if you want server-side message storage.
